# Bug Hunter

Bug Hunter is a full-stack bug tracking application for managing software issues from report to resolution. It combines a React-based frontend with an Express backend so users can sign in, browse bugs, add comments, and receive real-time notifications.

## Features
- User authentication and protected routes
- Bug listing and detailed bug views
- Comments on individual bugs
- Real-time notifications using Socket.IO
- Responsive interface built with React and Vite

## Tech Stack
- Frontend: React, TypeScript, Vite, React Router
- Backend: Node.js, Express, Knex
- Real-time communication: Socket.IO
